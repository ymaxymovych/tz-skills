# Як отримати токени (безкоштовно і майже безкоштовно)

Скілам потрібні **три різні LLM-моделі різних вендорів**. Найдешевший набір коштує **$0**:
твій Claude Code + дві безкоштовні моделі NVIDIA NIM. Нижче — прямі лінки і кроки.

---

## 1. NVIDIA NIM — БЕЗКОШТОВНО, без картки ⭐ рекомендовано

NVIDIA роздає 80+ hosted-моделей безкоштовно (OpenAI gpt-oss, MiniMax, Llama, Kimi та ін.). Картка не потрібна.

### Реєстрація і ключ

1. Відкрий **https://build.nvidia.com** → **Sign up / Login** (можна через Google, картку не просять).
2. Перейди на **https://build.nvidia.com/settings/api-keys**
   (або відкрий будь-яку модель у каталозі → кнопка **Get API Key**).
3. Натисни **Generate API Key**. Зʼявиться ключ із префіксом **`nvapi-...`**.
4. **Скопіюй його одразу** — повністю він показується лише раз.
5. Пропиши у змінну оточення:

   ```bash
   echo 'export NVIDIA_API_KEY="nvapi-ТВІЙ_КЛЮЧ"' >> ~/.bashrc
   source ~/.bashrc
   ```

### Що корисно знати

- **Безкоштовні кредити:** ~**1000** при реєстрації; ще до **4000** можна попросити через
  форум/форму → разом до **5000** безкоштовних кредитів.
- **Ліміт:** ~**40 запитів/хв** на модель (на рівні акаунту).
- **Ендпойнт** (OpenAI-сумісний, диспетчер уже налаштований): `https://integrate.api.nvidia.com/v1`

### Рекомендовані безкоштовні моделі (id для поля `model` у `providers.json`)

| id моделі | навіщо | вендор |
|---|---|---|
| `openai/gpt-oss-120b` | сильне міркування, відповідає за ~1 с — гарний критик | OpenAI |
| `minimaxai/minimax-m3` | самостійний вендор, ~8 с | MiniMax |
| `meta/llama-3.2-90b-vision-instruct` | резерв третього вендора, ~30 с | Meta |

> ⚠️ NVIDIA знімає моделі без попередження: `deepseek-ai/deepseek-r1` дає 404, `qwen/qwen2.5-coder-32b-instruct` — «end of life» з 12.05.2026. Таблиця вище перевірена живим викликом **01.09.2026**. Перед першим запуском і після будь-якої паузи — `bash ~/tz-skills/lib/llm-critic.sh --smoke-all`.

> Точні актуальні id — у картці кожної моделі на build.nvidia.com (кнопка коду показує рядок `model="..."`).

## 2. OpenRouter — один ключ до сотень моделей (є безкоштовні + дуже дешеві)

Потрібен, якщо хочеш підключати платні фронтир-моделі або більше різноманіття вендорів.

### Реєстрація і ключ

1. Відкрий **https://openrouter.ai** → **Sign in** (email або GitHub, **картка не потрібна** для старту).
2. Створи ключ: **https://openrouter.ai/keys** → **Create Key**. Формат — `sk-or-...`.
3. Пропиши у змінну оточення:

   ```bash
   echo 'export OPENROUTER_API_KEY="sk-or-ТВІЙ_КЛЮЧ"' >> ~/.bashrc
   source ~/.bashrc
   ```

### Безкоштовні моделі (без поповнення)

- Моделі з суфіксом **`:free`** коштують **$0/токен** (напр. `deepseek/deepseek-r1:free`).
- Ліміти без поповнення: **20 запитів/хв** і **50 запитів/день**.
- ⚠️ Важливо: **щоб підняти денний ліміт з 50 до 1000 назавжди — треба разово поповнити на $10**
  (не $5). Поповнення не згорає. Тобто:
  - хочеш лише безкоштовні моделі частіше → клади **$10 один раз**;
  - хочеш дешеві платні моделі → вистачить і **$5** (мінімальне поповнення).

### Як поповнити баланс (перші $5)

1. Відкрий **https://openrouter.ai/settings/credits** (або **Credits** у меню профілю).
2. **Add Credits** → введи суму. **Мінімум — $5.**
3. Оплата карткою (підтримується і 3-D Secure). Для розблокування 1000/день free-tier клади **$10**.
4. Баланс зʼявиться одразу; він не має терміну дії.

### Найдешевші рекомендовані платні моделі

Актуальні ціни (вони змінюються!) дивись тут, відсортовано від найдешевших:
**https://openrouter.ai/models?order=pricing-low-to-high**

Перевірені «дешево, але розумно» родини (звіряй live-ціну на сторінці вище):

| id моделі (приклад) | навіщо |
|---|---|
| `deepseek/deepseek-r1` | найкраще співвідношення ціна/міркування |
| `deepseek/deepseek-chat` | ще дешевше, швидше |
| `google/gemini-2.5-flash` | дешева, швидка, добре бачить структуру |
| `qwen/qwen-2.5-72b-instruct` | сильна на коді |
| `openai/gpt-5-mini` | дешевий вендор-різновид для незалежності |

> Один прогін `/tz-verify` великого ТЗ на платних моделях — це десятки тисяч токенів.
> На дешевих моделях це центи, але не нулі. Профіль на NIM (безкоштовний) для навчання — оптимальний старт.

## 3. Локальні CLI (опційно, замість API)

Якщо не хочеш API-ключі — став CLI, вони теж працюють як слоти:

- **Claude Code CLI** — вже є, якщо ти читаєш це в Claude Code.
- **OpenAI Codex CLI:** `npm install -g @openai/codex`, потім залогінитись.
- **Google Gemini CLI:** встанови за офіційною інструкцією Google і залогінься.

Диспетчер `lib/llm-critic.sh` викликає їх правильно — треба лише щоб команда була в `PATH`.
