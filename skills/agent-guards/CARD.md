# Картка для карти скілів: agent-guards

**Що дає**
Запобіжники для агентів Claude Code: хуки самі виправляють або відхиляють команди, на яких агенти щотижня гублять
години, — `$` і лапки в `git commit`, JSON у `curl`, кирилицю в cp866/cp1251, шляхи Git Bash на Windows, `.env`,
виконаний як код, промпт, з'їдений прапором `claude -p`. Плюс розмикач петель (3-тя однакова відмова → підказка,
6-та → відмова повтору) і скрипт заміру «до/після».

**Для чого**
Щоб агент не палив час і токени на механічних грабках оболонки й не зациклювався на відмові: помилку ловить хук
до виконання, а не правило в CLAUDE.md, яке модель забуває. Чесно про цифри: замір автора 01–08.11.2026 —
≈115 збоїв лапок і кодування за 8 днів та ≈1 100 механічних збоїв агентів за тиждень; ефект запобіжників ми
ще міряємо (`measure.py` дає змогу виміряти на власних сесіях).

**Від вас**
Нічого, крім одного речення Claude. Python 3.8+ (на Windows — разом із Git Bash). З'явиться 5 записів
у `~/.claude/settings.json` (копія до цього робиться; чужі хуки не чіпаються). Спершу хуки лише попереджають;
відмову вмикаєте самі, коли побачите лог без хибних спрацювань. Вимкнути: `AGENT_GUARDS_OFF=1`.
Не перевірено на macOS.
