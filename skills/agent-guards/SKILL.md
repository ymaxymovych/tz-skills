# /agent-guards — механічні збої агентів прибираємо хуком, а не проханням

## Навіщо

Агенти Claude Code раз у раз гублять час на однакових механічних граблях: `$` і зворотна лапка зникають із
тексту в `git commit -m`, JSON у `curl -d '{…}'` ламається, кирилиця перетворюється на кракозябри (cp866/cp1251),
Git Bash на Windows «перекладає» шляхи (`HEAD:path`, `/app:/data`), `.env` виконується як код, а фонові
`claude -p --allowedTools … "промпт"` мовчки з'їдають промпт. Правило в CLAUDE.md модель забуває, хук — ні.

Замір автора комплекту (01–08.11.2026, лише його транскрипти Claude): ≈115 збоїв лапок і кодування за 8 днів
і ≈1 100 механічних збоїв агентів за тиждень. **Ефект запобіжників ми ще міряємо** — цифр «після» поки нема;
`measure.py` дає вам змогу виміряти це на власних сесіях.

## Що ставиться

| Хук | Подія | Що робить |
|---|---|---|
| `shell_guard.py` | PreToolUse, `Bash`/`PowerShell` | **Виправляє сам:** `-X utf8` після `python`/`py`; `MSYS_NO_PATHCONV=1` перед `git show/log/diff… <ref>:<path>`, `gh api /…`, `-v /a:/b` (лише Windows/Git Bash). **Попереджає, потім відхиляє:** `git commit -m` з `$`/зворотною лапкою/`!`/переносом → `-F`; `gh … --body` → `--body-file`; JSON у `curl -d` → `--data-binary @файл`; `. .env`/`source .env`/`export $(cat .env)`. **Відхиляє одразу:** `claude -p` із прапором-списком (`--allowedTools`, `--disallowedTools`, `--add-dir`, `--mcp-config`, `--tools`, `--betas`, `--file`) перед позиційним промптом без stdin. **Лише попереджає:** `python -c`/`node -e`/`ssh host '…'` довші за 400 символів. Лапки, heredoc і PowerShell here-string — це дані, їх хук не чіпає. |
| `loop_breaker.py` | PreToolUse + PostToolUseFailure | 3-тя однакова відмова того самого інструмента з тим самим текстом → жорстка підказка «зміни підхід»; 6-та → відмова повтору. Звичайний ненульовий код виходу (червоний тест) відмовою не вважається. |
| `tool_hints.py` | PreToolUse + PostToolUseFailure | Підказки до типових збоїв; відхиляє `computer type` довшого за 300 символів у браузері (зависає). |

Хук ніколи не видає `permissionDecision: "allow"` — виправлена команда проходить звичайні дозволи.
Будь-який виняток усередині хука → код 0 без виводу (команда йде без змін). Лог:
`~/.claude/logs/agent_guards.jsonl` (час, правило, дія, перші 200 символів команди).

## Встановлення (один раз; повторний запуск безпечний)

Сід для Claude — одне речення: «Прочитай `~/tz-skills/skills/agent-guards/SKILL.md` і встанови запобіжники».

Що робить Claude:
1. `git -C ~/tz-skills pull` (немає клону — `git clone https://github.com/ymaxymovych/tz-skills ~/tz-skills`).
2. `bash ~/tz-skills/skills/agent-guards/install.sh` (`KIT_LANG=en` — англійські повідомлення хуків).
   Копіює три хуки в `~/.claude/hooks/`, робить копію `~/.claude/settings.json`, додає 5 записів (чужі хуки не
   чіпає, другий запуск нічого не дублює) і перевіряє кожен хук живим викликом.
3. Показує таблицю результату; червоні рядки — чек-лист «що зробити».

Хуки діють у **нових** сесіях Claude Code. Python 3.8+ потрібен (на Windows — разом із Git Bash).

### Режим відмови

Спершу хуки лише **попереджають** (правила `commitmsg`, `ghbody`, `curljson`, `dotenv`). Через кілька днів
перегляньте лог на хибні спрацювання і вмикайте відмову: `echo all > ~/.claude/hooks/agent_guards.enforce`
(або через кому — лише потрібні: `commitmsg,ghbody`). `claudep` відхиляється завжди, `inline` — лише попередження.

## Вимкнути

`AGENT_GUARDS_OFF=1` у середовищі (або в `settings.json` → `"env": {"AGENT_GUARDS_OFF": "1"}`) вимикає всі хуки
без видалення. Повністю прибрати — видалити записи з `agent_guards`-хуками з `~/.claude/settings.json`
(копія до встановлення лежить поруч: `settings.json.bak-agent-guards-<час>`).

## Заміряти ефект

```bash
python measure.py --from 2026-11-01 --to 2026-11-08 --out before.txt   # до встановлення
python measure.py --from 2026-11-15 --to 2026-11-22 --out after.txt    # через тиждень після
```

Скрипт читає `~/.claude*/projects/**/*.jsonl` і рахує невдалі виклики за категоріями: кодування, лапки bash, JSON,
PowerShell, MSYS, «не та оболонка», петлі відмов; додає, що хуки виправили чи відхилили. Порівняйте підсумки.

## Підказки, які варто знати (не хуки — звички)

- **Довгий текст у браузері** — через `form_input(ref, value)`, а не `computer type` (довгий ввід зависає по CDP).
- **Очікування** — фонова команда (`run_in_background`) або цикл `until <умова>; do sleep 5; done` у фоні, а не
  голий `sleep` у foreground.
- **Фонові робітники `claude -p`:** промпт — через stdin (`claude -p … < промпт.md`), а щоб у робітника лишились
  запобіжники й більше нічого з ваших налаштувань, — `--setting-sources project,local --settings
  worker-settings.example.json`. **Не** `disableAllHooks`: він вимикає й запобіжники.
- **Звіт робітника — не доказ.** Перевіряйте PR і діф, а не слова «зробив».

## Як перевірити, що все працює

```bash
python -X utf8 -m unittest discover -s ~/tz-skills/skills/agent-guards/tests
```

Не перевірено на macOS: тести і встановлення прогнано лише на Windows (Git Bash). Правило MSYS на macOS/Linux
свідомо не діє; решта правил від платформи не залежить.
