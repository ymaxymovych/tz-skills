# Шаблон паспорта — заповнює Claude

Скопіюй структуру нижче в `rozbir/TASK_PASSPORT.md` після першої розповіді.
Замінюй маркери; відсутні відомості — «невідомо», а не вигадані заповнювачі.
Зберігай відповіді й причини суттєвих змін при оновленні, не починай документ заново.
Метадані — на початку файлу, у YAML. `stop_after: spec` зберігай у кожній ревізії.

Статуси (чернетка починається з `ПОТРІБНІ_ДАНІ`):
- `ГОТОВО`: є реальний випадок, межа, критерій «стало краще», облік матеріалів,
  повний Deep Research, два конкретні приклади, перевірені підстави рекомендації,
  три підходи, рішення та пояснення студента своїми словами. Суттєвих прогалин
  для чернетки ТЗ немає; це не підтвердження попиту чи готовності програмувати.
- `ГОТОВО_З_УМОВАМИ`: рамка й пояснення студента є, повний звіт збережений, але
  бракує перевірки ключового джерела, другого доказового прикладу, досвіду покупців
  чи іншої важливої гіпотези. Умову названо в рекомендації та студент явно погодив
  напрям із цією умовою; не видавай такий прохід за повністю перевірений.
- `ПОТРІБНІ_ДАНІ`: розбір триває або немає реального випадку, повного звіту,
  пояснення студента, зрозумілого напряму чи критичного матеріалу для нього.
  Запиши блокер і одну дію продовження; етап 2 ще не пропонуй.

Позначай джерело біля кожного важливого факту: `[зі слів, дата]`,
`[з документа materialy/файл, сторінка/аркуш/діапазон]`,
`[з дослідження research-01.md, URL; перевірено/не перевірено]`, `[припущення]`.
Погодження рішення не змінює статус його неперевірених підстав.

```markdown
---
stage1_status: ПОТРІБНІ_ДАНІ
stop_after: spec
date: YYYY-MM-DD
revision: 1
---

Дослідження: [не підготовлено / підготовлено / запущено / часткове / завершено / недоступне].
Запит і тред: [research-01.md, якщо вже існує].
Переказ задачі: [очікуємо / підтверджено / виправлено, дата].
Пояснення студента своїми словами: [очікуємо / точні слова, дата].

[Хто, в якій ситуації, що не може зручно зробити й який наслідок.]

[Тригер → дії/учасники/файли → труднощі → результат; реальний приклад.]
[Частота, час, помилки: одиниці й джерела або «невідомо».]

## Що з документів
[Підтвердження й суперечності; критичне непрочитане або «матеріалів немає».]

[Вихідне бачення; що обов'язкове, що бажане; не підміняє обраний напрям.]

[Спростити процес / налаштувати готове / створити своє: користь, ручні дії,

## Наступний крок
[Продовжити конкретну дію розбору або створити лише чернетку TZ.md за паспортом.]
Етап 1 зупиняється тут. ТЗ, дизайн і програмування автоматично не запускаються.
```
