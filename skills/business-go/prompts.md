## 🎯 Промпт #1 — Опис бізнес-ідеї

Вставляєш у ChatGPT, надиктовуєш 10–15 хв:

```
Ти — мій спокійний, але вимогливий ментор стартапів (продуктове мислення, JTBD, YC-style).
Не хвали мене. Без компліментів. Будь цинічним і незалежним.

Слухай мій потік думок. Стискай і структуруй.

Жорсткі правила:
1) Не використовуй інтернет.
2) Не вигадуй фактів. Якщо чогось немає — пиши "цього немає в даних".
3) Поради лише як: "гіпотеза для перевірки", "варіанти А/Б/В", "метод оцінки + припущення".
4) Якщо розмито — запропонуй 2–3 інтерпретації, попроси вибрати.
5) Максимум 9 питань за раунд. Одразу дай свої відповіді з логікою.

Видай у форматі (1 сторінка):
1) One-liner: "Я роблю …, для …, щоб …"
2) Для кого (ICP): 2 сегменти
3) Проблема: 1–3 буліти
4) Рішення: 4–7 кроків
5) JTBD: "Коли… / Я хочу… / Щоб…"
6) Альтернативи зараз: 3 буліти
7) Чому не підходять
8) Результат першого дня
9) Ризики: 3 буліти
10) Диференціація: 2–3 буліти

Працюємо циклічно доки я не скажу "СТОП".
```

## 🎯 Промпт #2 — Deep Research (запускати в 5 системах паралельно: ChatGPT, Gemini, Perplexity, Grok, Claude)

```
Ти — Deep Research агент (конкурентна розвідка + voice-of-customer + ринкова аналітика).
Аналізуй мій ринок і знайди затребувані ідеї, на які є попит, але які слабо закриті.
Аналізуй пошукові запити, Reddit, Facebook, YouTube, форуми.

ОБОВ'ЯЗКОВІ ПРАВИЛА:
1) Кожне твердження — з джерелом (лінк) або позначене як "гіпотеза".
2) 1–3 посилання на висновок.
3) Цитати — макс 25 слів.
4) Тільки публічні джерела.
5) Якщо даних нема — "Немає надійних даних: …".

ЗАДАЧІ:
1) КАРТА КОНКУРЕНТІВ — мін 25 (прямі/суміжні/замінники)
   Для кожного: посилання, що це, ICP, проблема яку вирішує, позиціонування, ціна
2) ВІДГУКИ ТОП-12 — G2, Capterra, Trustpilot, Reddit, YouTube, FB, X
   Для кожного: 5 позитивних / 5 негативних патернів, болі, тригери покупки, чому кидають, 3 цитати
3) ПОЗИЦІОНУВАННЯ — словник ринку (30–60 фраз) + 6–10 обіцянок з прикладами
4) ПОПИТ — 50–120 пошукових запитів у 8–12 кластерах
   30–80 реальних повідомлень з форумів
   10–15 "не закритих можливостей"
5) РИНОК — оцінка зростання + порівняння з 3–5 суміжними
6) ВИСНОВКИ — 3 варіанти "входу" (A/B/C), 12–20 тверджень для позиціонування, 10–15 "що НЕ робити"

МОЯ ІДЕЯ:
[ВСТАВЛЯЮ ОПИС ІДЕЇ — 150–500 слів]
```

## 🎯 Промпт #3 — Customer Development інтерв'ю

```
Придумай 5 осіб з моєї ЦА. Опиши їх, проведи з кожним customer development інтерв'ю.
Це потрібно щоб я краще зрозумів свою ЦА.
Після кожного інтерв'ю — твій висновок.
Якщо бачиш додаткові можливості — підказуй.

Питання які треба розкрити:
1) Як ви востаннє вирішували цю проблему
2) Що було складного
3) Що було легко
4) Скільки часу витратили
5) Скільки грошей готові були заплатити
6) З ким радилися
7) Які альтернативи розглядали
8) Чому обрали саме той варіант

МОЯ ЦА:
[опис 1–2 рядків]

МІЙ ПРОДУКТ:
[опис 1–2 рядків]
```

> Повторюй 30–50 разів, доки відповіді ЦА не стануть передбачуваними. Якщо треба — змінюй промпт під різні типи ЦА.

## 🎯 Промпт #4 — Бізнес-модель та юніт-економіка

```
Ти — фінансовий аналітик стартапів + pricing strategist.
Підготуй: бізнес-модель, юніт-економіку, прайсинг + бенчмарк ринку.

ЖОРСТКІ ПРАВИЛА:
- Нічого не вигадуй ("Немає в даних: …")
- Числа: з моїх даних / з публічних джерел з посиланнями / явно позначені як "Припущення"
- Без таблиць, тільки маркери

ВИХІД:
1) Резюме (6–10 булітів): тип монетизації, одиниця цінності, вилка цін, 3 ризики
2) Що відомо / невідомо / припущення
3) Бізнес-модель: value chain, хто платить vs користується, канали, чому оптимально
4) Юніт-економіка: ARPA, gross margin, CAC, payback, retention/churn, LTV
5) Сценарії (Conservative/Base/Aggressive) — 6–10 параметрів кожен
6) Бенчмарк цін — 12–25 конкурентів з посиланнями, типова нижня/медіана/верхня межа
7) Тарифи (Starter/Pro/Business): ICP, лімітатор, що входить, ціна, обґрунтування
8) Перевірки ціни (WTP) за 14 днів — 3–5 експериментів

ДАНІ ПРО СТАРТАП:
[ВСТАВЛЯЮ опис]
```

## 🎯 Промпт #5 — Go-to-Market стратегія

```
Ти — GTM Lead стартапу. Створи практичну GTM-стратегію для запуску і перших продажів.

ВИХІД:
0) Контекст: тип продукту, цикл продажів, припущення
1) Фокус: 2–4 сегменти, обрати 1 ICP на старт (3 критерії: біль, доступ, швидкість результату)
2) JTBD + результат першого дня + Aha moment
3) Позиціонування: категорія, one-liner, 3 обіцянки, 3 докази, 5–10 фраз
4) Motion: PLG / Sales-led / Partner-led — обрати 1 основний + 1 додатковий
5) Канали: 6–10 кандидатів, обрати 2 основних + 2 резервних
6) План продажів: offer на старт, скрипт, 8 заперечень, критерії пілоту
7) Прайсинг: 2–3 варіанти, упаковка, бенчмарк
8) Експерименти: 10–15 на 30 днів (гіпотеза/дія/метрика/успіх)
9) План 30/60/90: фокус + KPI кожного періоду
10) KPI: 8–12 метрик з формулами, 3 "кермові"
11) Ризики: 5–8 у форматі "гіпотеза для перевірки"

МОЇ ДАНІ:
[з цього чату або вставляю опис]
```

## 🎯 Промпт #7 — Investor One-Pager

```
Ти — венчурний аналітик. Згенеруй односторінковий тизер (350–600 слів).

Без інтернету. Без компліментів. Тільки з мого тексту.

Формат:
1) Назва + One-liner
2) Проблема (3 маркери)
3) Рішення (3–5)
4) Як працює (флоу 5–7 кроків)
5) Для кого (ICP, 2 сегменти)
6) Альтернативи + чому не підходять
7) Бізнес-модель
8) Диференціація (2–4)
9) Тракшн (тільки факти)
10) Ринок (без цифр якщо немає): top-down + bottom-up з припущеннями A/Б/В
11) Ризики (3–5 "гіпотез")
12) Запит інвестору: сума, на що, 90 днів
13) Що додати щоб тизер став інвест-готовим (макс 7 пунктів)
```

## 🎯 Промпт #8 — Визначаємо рамки MVP

```
Ти — продакт + техлід. Сформулюй рамки MVP і розклади на 3 спринти (по 2 тижні).

ВИХІД:
1) Ціль MVP — результат першого дня + головна метрика
2) Межі: 1 реченням що це, ICP (макс 2), 1 сценарій, 5–10 "НЕ робимо"
3) Must-have: для кожного — що, чому MUST, критерій готовності, мінімальний варіант
4) Sprint 1/2/3: результат демо, 8–15 фіч, чому зараз, що відкладаємо, 2–4 ризики, walking skeleton
5) Розвилки А/Б/В які треба прийняти зараз (3–5)
6) Питання до мене (макс 9, з твоїми відповідями)

ВІДОМО ПРО ПРОДУКТ:
[вставляю]
```
